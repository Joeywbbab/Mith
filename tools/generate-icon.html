🏔️ Mith Icon Generator

生成不同尺寸的应用图标 PNG 文件

使用说明：
方法 1（推荐）： 点击"生成并保存到 icons 文件夹"，会自动将所有图标文件保存到 src-tauri/icons/
方法 2： 点击"生成所有尺寸并下载"，然后手动将文件复制到 src-tauri/icons/

生成的文件：
- 32x32.png - 小图标
- 128x128.png - 中等图标
- 128x128@2x.png (256x256) - Retina 图标
- icon.png (512x512) - 主图标
- icon.icns - macOS 图标（需要手动生成，见下方说明）
